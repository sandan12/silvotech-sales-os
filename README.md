# SilvoTech Sales OS

Отдельная рабочая система для квалификации B2B-возможностей, технического
сопоставления товаров и быстрого обновления контекста клиента.

## Первая версия

- три рабочих режима: «Сегодня», «Возможности», «Результат»;
- активный портфель вместо всей базы CRM;
- реальные примеры Flow Solution и Aqua‑Trend;
- единый ввод заметки или голосовой расшифровки;
- предварительный просмотр изменений до записи;
- адаптер данных, который сначала работает на снимке CRM;
- будущая прямая связь с существующим Supabase.

## Запуск


## Подключение CRM в режиме чтения

1. Скопировать `.env.example` в `.env.local`.
2. Указать URL и publishable key существующего Supabase.
3. Добавить домен нового приложения в Supabase Auth → URL Configuration.
4. Включить этот же домен в redirect URLs провайдера Google.

Без переменных окружения приложение автоматически работает на компактном
снимке CRM. С настроенным Supabase после входа через Google оно читает актуальные
счётчики клиентов, событий и товаров. Запись в CRM в версии 0.2 отключена.

## Архитектурное правило

Текущая CRM не переделывается. Новое приложение использует её как источник и
получатель общих данных. Запись в CRM будет включена только после проверки
сценария предварительного просмотра и подтверждения изменений.
